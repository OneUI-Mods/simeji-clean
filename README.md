# Simeji Clean

[English](README.en.md)

SimejiでGoogle Playの検索欄を開いたとき、キーボードの上に出る白い広告・アプリおすすめパネルを非表示にするXposedモジュールです。

通常のキー、スキン、変換候補は対象外です。Google Play以外の入力欄と、Playストア本体の広告には変更を加えません。

## 機能

- 広告パネルの非表示をスイッチでON／OFF。
- アイコンとカードで、準備完了・広告拒否・未確認・非対応・クラッシュ保護を表示。
- APK内のレイアウト参照、型、処理の目印、実際の呼び出し関係からフック先を動的に検索。APKが更新された場合は再解析し、同じAPKではキャッシュを使用。
- 候補が複数、必要な根拠が欠ける、設定を取得できない場合は標準動作に戻る。
- Material 3、システムに従うライト／ダークとダイナミックカラー。
- 日本語・英語・韓国語・簡体字・繁体字。最初はOSの言語を使用し、アプリ内から言語設定を開ける。
- Simejiだけを読み込み直すボタンと、起動時のroot権限要求。現在Simejiを使っている場合は読み込み直し後もSimejiへ戻し、別のキーボードを選択中なら変更しない。
- 連続クラッシュ時のフック停止と保護解除。
- MIT Licenseと、同梱依存ライブラリのライセンス全文をアプリ内に表示。

## 必要な環境

- Android 12以降。
- modern libxposed API 102に対応したVector等の環境。legacy API 82には対応していません。
- Simeji（`com.adamrocker.android.input.simeji`）。実機の解析元は23.6.1／versionCode 966です。

通常の未root端末にAPKを入れるだけでは動作しません。本アプリ自身のsu権限は読み込み直し用で、広告の非表示処理は既存のXposed環境を利用します。suを許可しなくても設定とフックは使えます。

## 導入

1. [Releases](https://github.com/OneUI-Mods/simeji-clean/releases)の署名済みAPKをインストールし、**Simeji Cleanを一度開きます**。
2. VectorでSimeji Cleanを有効にし、スコープに**Simejiだけ**を追加します。
3. Simejiを読み込み直し、Playストアの検索欄を開きます。端末・ソフト再起動は不要です。
4. アプリの状態表示と、実際に白いパネルが表示されないことを確認します。

Playストア、SystemUI、Androidシステム、他の入力先アプリをスコープへ追加する必要はありません。初回導入や更新直後に設定を取得できなかった場合、アプリを開き直してからキーボードを出し直すと、入力開始イベントで設定の取得を再試行します。

## 停止・復旧

通常はスイッチをOFFにします。Vectorでモジュールを無効化してSimejiを読み込み直すことでも停止できます。システムパーティション、SimejiのAPK、既存の広告設定は書き換えません。

短時間にSimejiのJava／nativeクラッシュが3回続いたと確認できた場合は、次の起動でフックを止めます。アプリの「クラッシュ保護を解除」の後にSimejiを読み込み直すと再試行できます。通常の強制終了をクラッシュとは数えません。OS全体の起動ループを完全に防ぐ保証ではありません。

## 対応と制約

動的検索は将来のすべての更新を保証するものではありません。クラス名や数値のリソースIDだけに依存しない構成ですが、レイアウト名や判定処理の目印自体が失われた場合は非対応として停止します。

通信を遮断する機能ではありません。入力内容や変換候補は取得・記録せず、入力先のパッケージ名だけで適用を判断します。本アプリは通信権限を要求しません。
